# Postal/PIN scorecard

No population scorecard has been claimed. Postal extraction is implemented only as country-aware **postal-like** detection: US ZIP, India PIN, and France five-digit forms. It is soft evidence, not a hard retrieval filter.

The required full scorecard (source/split/country detection, agreement, collision, recall, and candidate-cost tables) is blocked from execution on the present machine by available RAM/disk. It must be run from a disk-backed experiment environment before postal is included in any final candidate union.
